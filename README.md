# SSD Ummah — Islamic Website

A responsive Islamic website concept created to provide a clear and welcoming digital space for sharing Islamic learning resources and community information.

## Live Demo

[View the live website](https://mkaceduet-hub.github.io/islamic-website-ssd-ummah/)

## Project Overview

SSD Ummah is a front-end portfolio project in the Islamic website category. It demonstrates how structured content and responsive design can support an accessible online learning and information experience.

## Technologies

- HTML5
- CSS3
- JavaScript

## Getting Started

1. Clone or download this repository.
2. Open the project folder in Sublime Text or another code editor.
3. Open `index.html` in a modern web browser.
